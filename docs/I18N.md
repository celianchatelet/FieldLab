# Internationalisation FR/EN

FieldLab conserve ses noms de scénarios, matériaux et conditions en français dans l’API. Le module `fieldlab/i18n.py` fournit un catalogue central et `traduire_interface()` ; ce choix est plus sûr qu’un remplacement immédiat par `QTranslator` dans une base de code où plusieurs textes visibles servent aussi d’identifiants métier.

`ComboBoxTraduit` stocke la valeur française dans un rôle Qt séparé, affiche sa traduction et retourne toujours la valeur source via `currentText()`. Ainsi, passer l’interface en anglais ne change ni les clés des presets ni les fichiers projet. La langue est enregistrée dans `QSettings` sous `interface/langue`.

Pour ajouter une chaîne :

1. écrire la chaîne source en français dans le widget ;
2. ajouter sa traduction exacte au dictionnaire `EN` si elle n’est pas couverte ;
3. utiliser `ComboBoxTraduit` pour toute nouvelle liste métier ;
4. appeler `tr()` pour les messages construits après l’initialisation ;
5. ajouter un test qui vérifie à la fois le texte affiché et la valeur métier.

Les descriptions pédagogiques longues possèdent un catalogue dédié dans `scenarios_pedagogiques.py`, tandis que les textes statiques, infobulles, menus et actions sont retraduits en place par le parcours des objets Qt.
